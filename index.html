01

Project Overview

🎯

Aim

To develop an in-silico computational pipeline for constructing a genomic DNA library and identifying potential industrial enzyme candidates from microbial genomes.

🔬

Objectives

  • Retrieve complete microbial genomes from NCBI.
  • Construct genomic DNA libraries using 5-kb fragments.
  • Predict protein-coding genes using Prodigal.
  • Obtain GFF3 and predicted protein FASTA outputs.
  • Map predicted genes to genomic library fragments.
  • Functionally screen candidate proteins.
  • Characterize selected enzyme candidates structurally.

Module 1 — Genomic Library Construction

Workflow

  1. Genome retrieval
    Complete microbial genome sequences are obtained from the NCBI genome database.
  2. Genome preparation
    The downloaded FASTA/FNA sequence is uploaded to Google Colab.
  3. 5-kb fragmentation
    Biopython is used to divide the genome into consecutive fragments of approximately 5,000 bp.
  4. FASTA library generation
    Each fragment is assigned a unique identifier and saved as a genomic library FASTA file.
  5. Quality check
    Fragment count, total sequence length and fragment size are recorded.

Module 3 — Structural Characterization & Computational Pipeline Development

Final Computational Stage

  1. Candidate selection
    Select high-priority proteins from the functional screening stage.
  2. Gene–fragment mapping
    Match GFF3 gene coordinates with the 5-kb genomic library fragments.
  3. Protein characterization
    Examine predicted protein length, domains and functional annotations.
  4. Structural prediction
    Submit selected protein sequences to an appropriate online structure-prediction resource.
  5. Candidate ranking
    Prioritize candidates according to functional evidence and structural features.

Conclusion

The developed computational pipeline integrates genomic library construction, gene prediction, functional screening, gene–fragment mapping and structural characterization.

This workflow provides a systematic approach for identifying and prioritizing potential industrial enzyme candidates from microbial genomes before experimental validation.
